# 观象 GuanXiang

> **观其象，知其因。**

观象是面向 [DeepSeek Harness](https://github.com/modestoma/deepseek-harness)（dsh）的日志分析插件。

名称取意于《周易》的观象思想：以日志为象，以推理为径，从复杂的系统运行痕迹中洞察异常、关联线索、追溯根因。

中文名统一使用「观象」，英文品牌统一使用「GuanXiang」。

## 项目状态

项目处于构思与初始化阶段，尚未发布可用版本。本文档描述的是规划中的产品能力，接口与实现会随设计推进而调整。

## 核心能力

观象的能力按名称拆分为三个层次，由浅入深：

| 能力 | 关注点 | 规划内容 |
|---|---|---|
| **观** | 看见 | 解析日志、提取线索、发现异常 |
| **象** | 理解 | 理解系统行为、关联事件、构建问题全貌 |
| **推演** | 求因 | 借助 AI Agent 自主分析、验证假设、定位根因 |

### 观：解析日志，发现异常

- 解析常见的结构化与半结构化日志格式，统一为可检索的事件记录。
- 提取时间、级别、模块、请求标识、错误信息等关键字段作为线索。
- 识别错误突增、异常堆栈、频率偏离等可疑信号。

### 象：关联事件，构建全貌

- 按时间线、请求链路和组件关系关联分散的日志事件。
- 将多个异常信号归并为同一问题，还原问题发生的上下文。
- 呈现系统在问题时段内的行为全貌，为后续推演提供依据。

### 推演：自主分析，定位根因

- 由 AI Agent 基于「观」与「象」的结果提出根因假设。
- 主动检索更多日志与上下文，对假设逐一验证或排除。
- 输出可追溯的分析过程与结论，说明每个判断所依据的日志证据。

## 与 DeepSeek Harness 的关系

DeepSeek Harness 是基于 Cordis 的全插件化 Agent 框架：模型适配、工具注册、会话日志乃至 Agent 循环本身都是插件，新能力通过在已有扩展点上挂载插件来实现，而不是修改核心代码。

观象计划以 dsh 插件的形式交付：

- 以 Cordis 插件实现，通过 dsh 的工具注册等扩展点向 Agent 提供日志分析工具。
- 打包为 dsh bundle，可通过 `dsh plugin` 命令或 Web 端的插件管理页面安装到指定 profile。
- 所有可调参数通过插件配置暴露，可在 `cordis.yml` 或 profile 的 patch 文件中调整。

dsh 的插件机制参见其[架构文档](https://github.com/modestoma/deepseek-harness/blob/main/docs/architecture.md)与[扩展手册](https://github.com/modestoma/deepseek-harness/blob/main/docs/cookbook/extension-cookbook.md)。
